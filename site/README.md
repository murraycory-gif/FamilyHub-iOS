# HUB Circle site

Cloudflare Pages can publish this folder as-is.

Before publishing, replace the contact email in `config.js`. That file is the only place the address is set. Until it is a real address, the privacy page shows a visible line that the contact email is not set yet.

The privacy page is `privacy.html`. The app links to `https://hubcircle.pages.dev/privacy.html`.
